# Pixel Snap（Figmaプラグイン）

大まかに配置したデザインの「端数px」と「中央寄せのわずかなズレ」を一括で直すFigmaプラグイン。

- `34.5px` → `35px` のように X / Y / W / H を整数に丸める
- 親フレームの中央から数px以内にあるレイヤーを、中央にぴったり合わせる
- Auto Layout の padding / gap の端数も丸める

## インストール（開発用プラグインとして読み込む）

1. Figma **デスクトップアプリ**でファイルを開く（ブラウザ版では読み込めない）
2. メニュー → プラグイン → 開発 → 「マニフェストからプラグインをインポート…」
3. このフォルダの `manifest.json` を選ぶ

以降は プラグイン → 開発 → 「Pixel Snap」から起動できる。

## 使い方

1. 整えたいフレーム（またはレイヤー）を選択する
2. 「設定を開いて実行」を起動
3. 「確認だけ」で変更予定の一覧を見る（行をクリックするとそのレイヤーへズーム）
4. 問題なければ「整える」
5. 戻したいときは `Cmd/Ctrl + Z`（1回で全部戻る）

設定を決めたあとは「前回の設定ですぐ整える」でUIを出さずに実行できる。
よく使うならショートカットを割り当てると速い（Cmd/Ctrl + / のクイックアクションで「Pixel Snap」と打っても呼べる）。

## 設定

| 項目 | 既定値 | 内容 |
|---|---|---|
| 位置（X / Y） | ON | 位置を丸める |
| 位置の丸め単位 | 1px | 2 / 4 / 8px にすると8ptグリッド等に吸着させられる |
| サイズ（W / H） | ON | 幅・高さを1px単位に丸める |
| Auto Layout の余白・間隔 | ON | padding / gap を1px単位に丸める |
| 左右中央に近いものを中央へ | ON | |
| 上下中央に近いものを中央へ | OFF | |
| ズレの許容幅 | 3px | 中央からこの幅以内のものだけ寄せる。大きくしすぎると意図的な左寄せまで中央へ動く |

## 触らないもの

- Auto Layout の子レイヤーの位置（レイアウトが決めるため）
- サイズが「Hug」「Fill」のもの、テキストの自動幅・自動高さ
- インスタンスの中身（Figmaの仕様で動かせない）
- 回転しているレイヤーのサイズと中央寄せ（位置の丸めのみ行う）
- ロック中のレイヤー（設定で変更可）

## 注意

- 中央寄せの基準は「一番近い親フレーム」。グループは基準にならず、その外側のフレームが基準になる。
- 親と子の幅の偶奇が違う（例：幅400のフレームに幅101の要素）と、整数座標ではぴったり中央にできない。
  この場合は0.5pxずれることを一覧に「※」で表示する。
- 変更は親フレームの制約（Constraints）を無視して行うので、サイズを丸めても中の要素は動かない。
