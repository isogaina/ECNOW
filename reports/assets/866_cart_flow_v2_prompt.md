# 866 カート別フローチャート（差し替え版）画像生成プロンプト

変更理由：カラーミーショップはパターン③も選べる／STORESは③を選べない（2026年8月時点の各社仕様で確認）

## 生成プロンプト（そのまま貼り付け）

```
日本語のフローチャートを1枚作成してください。ECカートごとにオウンドメディアの設置パターンを選ぶ図です。

【全体スタイル】
- 白背景、フラットデザイン、影なし
- 角丸長方形（角丸8px程度）、枠線は細いグレー（#cfd4dc、1.5px）
- 矢印は細いグレーの直線＋小さな三角の矢頭、直角に折れる配線（カギ線）
- フォントは日本語ゴシック体（Noto Sans JP 相当）
- 横長（16:9程度）、余白を広めに取る
- 文字は黒（#1f2937）、装飾的な影やグラデーションは使わない

【構造：上から3段】

1段目（中央に1つ）
  「使っているカートは？」
  白背景・グレー枠の角丸長方形

2段目（横一列に6つ、等間隔）
  左から「Shopify」「makeshop」「futureshop」「BASE」「カラーミー」「STORES」
  すべて白背景・グレー枠の角丸長方形
  1段目の箱から下方向に伸びた線が、6つそれぞれへ矢印で分岐する

3段目（横一列に4つ）
  2段目から下へ矢印でつなぐ。接続は以下のとおり：

  ・Shopify / makeshop / futureshop の3つ → 1つ目の箱にまとめて合流
  ・BASE → 2つ目の箱へ（★オレンジの箱ではない。必ず2つ目の青い箱に入れる）
  ・カラーミー → 3つ目の箱へ
  ・STORES → 4つ目の箱へ

  ★配線の鉄則：3段目の4つの箱には、それぞれ必ず1本以上の矢印が入る。
    入ってくる矢印が0本の箱があってはならない。
    箱の真上に矢印の終点が来るよう、箱と矢印のX座標を揃えること。

  箱1（塗り #dbeafe 薄い青、枠 #3b82f6 青）
    見出し（大きめ・太字）：パターン① そのまま使える
    説明（小さめ）：ショップと同じドメイン配下に記事を置ける

  箱2（塗り #dbeafe 薄い青、枠 #3b82f6 青）
    見出し（太字）：パターン① ただし制約あり
    説明：ブログAppは無料 ルートドメインは使えない

  箱3（塗り #ffedd5 薄いオレンジ、枠 #f97316 オレンジ）
    見出し（太字）：パターン②または③ WordPressを別途用意
    説明：ショップをサブドメインに移せばルートにメディアを置ける

  箱4（塗り #fee2e2 薄い赤、枠 #ef4444 赤）
    見出し（太字）：ショップと別ドメインで用意
    説明：独自ドメインの持ち込みもサブドメインも不可 ③は選べない

【注意】
- 3段目の4つの箱は同じ高さに揃え、幅は文字量に応じて調整してよい
- 箱の中の説明文は見出しより2段階ほど小さく
- 「①」「②」「③」は丸囲み数字をそのまま使う
- 句読点（、。）は使わず、区切りは全角スペースで表現する
- 英語表記は Shopify / makeshop / futureshop / BASE / STORES の綴りを厳守（大文字小文字もそのまま）
```

## 差し替え後の alt テキスト

```
使っているECカート別にオウンドメディアの設置パターンを選ぶフローチャート。Shopify・makeshop・futureshopは同一ドメイン配下に記事を置けるパターン①、BASEはパターン①だがルートドメインが使えない制約あり、カラーミーショップはWordPressを別途用意するパターン②または③、STORESは独自ドメインの持ち込みもサブドメインもできずショップと別ドメインになる
```

## 旧版からの変更点（3箱 → 4箱）

| | 旧版 | 新版 |
|---|---|---|
| Shopify / makeshop / futureshop | パターン① そのまま使える | 変更なし |
| BASE | パターン① ただし制約あり | 変更なし |
| カラーミー | STORESと同じ「パターン② WordPressを別途用意」に合流 | **単独の箱へ。②または③** |
| STORES | 同上（カラーミーと合流） | **単独の箱へ。別ドメインで用意・③不可** |
